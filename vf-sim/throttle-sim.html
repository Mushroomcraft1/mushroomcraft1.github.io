Configure the train in the middle panel and its switching behaviour in the pulsing panel on the right.

Pulsing modes

  • ASYNC: Uses one fixed carrier frequency.
  • ASYNC-OSCILLATING: Oscillates the carrier between a minimum and maximum using the selected waveform.
  • ASYNC-SWEEP: Sweeps the carrier between a minimum and maximum as motor frequency rises.
  • SYNC: Uses a pulse count and has no carrier-frequency setting. It dynamically creates the pulsing.
  • SHE-PWM: Uses a pulse count and has no carrier-frequency setting. The pulsing is pre-computed.

JSON

JSON contains only the settings used by each selected mode. Settings belonging to a previous mode are removed when the mode changes.

Use JSON Editor to inspect, copy or load a train configuration.
